# Авторские скриншоты для PL Code Store

Этот PR **не должен быть объединён до загрузки трёх настоящих изображений**. Текст `vitrine/meta.json` подготовлен, но бинарные файлы со стороны ChatGPT недоступны GitHub-коннектору для прямой передачи.

1. Скачай архив `PLCodeStore_analitikhhru_screenshots.zip` из беседы и распакуй.
2. В GitHub переключись на ветку `vitrine/real-screenshots-2026-11`.
3. Открой папку `vitrine/screenshots/` (создай, если ещё нет), затем **Add file → Upload files**. Добавь `main.png`, `history.png`, `recruiting-support.png` — именно по этим путям.
4. Сохрани изменения в **эту же ветку**. Убедись, что изображения отображаются в GitHub и что на них нет персональных данных.
5. Только после этого сделай Merge PR. Тогда PLCodeStore прочитает новое содержимое из исходного репозитория при следующей сборке Pages.

**Значение проекта:** браузерная аналитика HH.ru, вакансии и резюме, STOCK/FLOW, история замеров, сценарный proxy recruiting-support. Это не фактический штат работающих рекрутеров.
